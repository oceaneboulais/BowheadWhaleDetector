# Get Professional 3D Diagram on Overleaf (5 minutes)

## Step 1: Copy LaTeX Code
```bash
cat /Users/oboulais/Public/Bowhead_DL_Project/architecture_diagrams_latex/autoencoder_arch.tex | pbcopy
```
*(This copies the LaTeX code to your clipboard)*

## Step 2: Go to Overleaf
1. Visit: **https://www.overleaf.com/**
2. Click **"Register"** (free account)
3. Verify email

## Step 3: Create Project with PlotNeuralNet Template
1. Click **"New Project"** → **"Upload Project"**
2. Download PlotNeuralNet template: https://github.com/HarisIqbal88/PlotNeuralNet/archive/refs/heads/master.zip
3. Upload the ZIP to Overleaf
4. Wait for it to extract

## Step 4: Replace Example with Your Autoencoder
1. In Overleaf file browser, find `pyexamples/` folder
2. Create new file: `autoencoder.tex`
3. Paste your code (Cmd+V from clipboard)
4. Set as **Main Document** (right-click → Set as Main Document)

## Step 5: Compile & Download
1. Click **"Recompile"** button
2. Wait 10-20 seconds
3. Click **"Download PDF"**
4. Open the beautiful 3D diagram!
